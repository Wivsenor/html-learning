## 二、盒子模型
### 1. 什么是盒子模型
盒子模型是 CSS 中常用于布局的基本概念：**文档中的每个元素都可以被看成一个矩形的盒子**。这个盒子从内到外包含四层：

```
┌─────────────────────────────┐
│           margin 外边距       │  ← 盒子与其他盒子之间的空间
│  ┌───────────────────────┐  │
│  │       border 边框      │  │  ← 盒子的边界
│  │  ┌─────────────────┐  │  │
│  │  │   padding 内边距  │  │  │  ← 内容与边框之间的空隙
│  │  │  ┌───────────┐  │  │  │
│  │  │  │ content 内容│  │  │  │  ← 文本、图片等
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| 层级 | 属性 | 含义 |
|---|---|---|
| 内容 | `content` | 盒子包含的文本、图片等实际内容 |
| 内边距 | `padding` | 围绕在内容内部，内容与边框之间的空隙 |
| 边框 | `border` | 围绕在内边距外部，是盒子的边界 |
| 外边距 | `margin` | 边框外部，当前盒子与其他盒子之间的空间 |

> **理解思路**：把元素想象成一个快递纸箱，内容是里面的东西，padding 是东西到纸箱内壁的缓冲，border 是纸箱本身，margin 是这个箱子和旁边箱子之间的距离。

`padding`、`border`、`margin` 都属于**复合属性**：可以通过一个属性同时设置多个样式。

### 2. 边框 `border`
#### （1）复合写法
`border` 一条属性可以设置边框的**宽度、样式、颜色**：
```css
.demo {
  border: 5px solid yellowgreen;
}
```

#### （2）边框样式 `border-style`
| 样式值 | 效果 |
|---|---|
| `solid` | 实线 |
| `dashed` | 虚线 |
| `dotted` | 点线 |
| `double` | 双实线 |

颜色可以写颜色名，也可以用 RGB 值或十六进制颜色值。

#### （3）拆分写法
也可以把边框拆成三个属性分别设置：
```css
.border-demo {
  border-style: solid;
  border-width: 10px;
  border-color: purple;
}
```

#### （4）四个方向的值顺序（上右下左）
边框有上、右、下、左四个方向，复合属性的值按**顺时针：上 → 右 → 下 → 左**排列：

| 值的个数 | 含义 |
|---|---|
| 1 个值 | 上、右、下、左四边相同 |
| 2 个值 | 第一个上下，第二个左右 |
| 3 个值 | 第一个上，第二个左右，第三个下 |
| 4 个值 | 上、右、下、左依次对应 |

没写全的方向会找对面的值补全：缺下找上，缺左找右。非零值必须带单位（如 `px`），写 `0` 可以不带单位。

#### （5）只设置单个方向
只想给某一条边加样式时，用方向属性：
```css
border-left: 10px solid brown;
```
对应的还有 `border-right`、`border-top`、`border-bottom`；每个方向还能继续拆成 `border-left-color` / `border-left-style` / `border-left-width`。

### 3. 内边距 `padding`
内容四周的留白，同样有上右下左四个方向：
```css
.demo {
  padding: 50px;  /* 上下左右内边距都是 50px */
}
```
方向属性：`padding-left`、`padding-top`、`padding-bottom`、`padding-right`。

### 4. 外边距 `margin`
盒子外侧与其他元素之间的间距：
```css
.demo {
  margin: 40px;  /* 上下左右外边距都是 40px */
}
```
方向属性：`margin-left`、`margin-right`、`margin-top`、`margin-bottom`。

> **理解思路**：掌握了边框的作用、样式、宽度、颜色，就能类推 `padding`、`margin` 的几十个方向属性该怎么用，不必逐个死记。

## 三、浮动
### 1. 五种网页布局方式
布局本质上都是**把盒子摆放到合适的位置**，常见方式有五种：

| 布局方式 | 说明 |
|---|---|
| 标准流（普通流 / 文档流） | 最基本的布局：块级元素占一行，行内元素一行放多个，按默认规定排列 |
| 浮动 | 改变元素默认排列顺序，让多个块级盒子并排 |
| 定位 | 精准定位页面中的某个元素 |
| Flexbox（弹性盒子） | 自适应布局，更轻松实现复杂排列 |
| Grid（网格） | 自适应布局，按网格排列 |

Flexbox 和 Grid 也被称为**自适应布局**，能让页面在手机端、电脑端等不同设备上更容易适应。实际开发中经常是多种布局方式掺杂在一起使用。

### 2. `float` 属性
浮动可以改变元素的默认排列顺序，让布局更灵活。**最典型的应用：让多个块级元素在同一行内排列显示。**

```css
float: left;   /* 左浮动 */
float: right;  /* 右浮动 */
float: none;   /* 不浮动（默认） */
```

- 浮动是**相对于父元素**进行的，只会在父元素内部移动
- **浮动 vs 行内块**：浮动元素相互贴靠在一起、没有缝隙；父级宽度装不下时，多出的盒子另起一行。行内块元素彼此之间会有缝隙，不如浮动方便

### 3. 浮动的三大特性
1. **脱标（脱离标准流）**：元素设置浮动后，脱离标准流的控制，移动到指定位置，不再保留原来所占的位置，就像漂浮在空中、脱离了地面
2. **一行显示、顶部对齐**：多个盒子同时设置浮动，会按属性值在一行内显示，并且顶端对齐排列
3. **具备行内块元素的特性**：不管原先是什么模式的元素，添加浮动后都会具有行内块元素相似的特性

### 4. 父元素高度坍塌与清除浮动
#### （1）高度坍塌是怎么回事
子元素浮动后会脱标，如果父元素**没有设置高度**，父元素的背景色、边框就包不住这些浮动子元素，这就是**父元素高度坍塌**。此时再往父元素后面写标签，文本会出现在浮动盒子中间，影响后续布局。

#### （2）清除浮动的两种常用方式
**方式一：父元素加 `overflow: hidden`**
```css
.father {
  overflow: hidden;
}
```
父元素没有显式设置高度也能被撑开。

**方式二：伪元素清除法**
给浮动元素的父元素加一个 `::after` 伪元素：
```css
.father::after {
  content: "";
  display: table;
  clear: both;
}
```

> **理解思路**：浮动让盒子飘起来、不再占原来的位置，父元素就"看不见"它们的高度；清除浮动就是让父元素重新把这些浮动子元素的高度算进去，把自己撑开。

## 四、定位
### 1. 定位概述
浮动虽然灵活，但不容易控制；**定位布局可以精准定位页面中的某一个元素**。反过来，定位元素缺乏灵活性，给空间大小和位置不确定的版面布局带来麻烦，所以要根据设计需求辩证选择。

定位通过 `position` 属性设置，再配合四个**偏移属性**确定位置：

| 偏移属性 | 含义 |
|---|---|
| `left` | 距离元素原本位置 / 参照对象最左边的距离 |
| `right` | 距离最右边的距离 |
| `top` | 距离最上边的距离 |
| `bottom` | 距离最下边的距离 |

### 2. 相对定位 `relative`
相对于元素**在文档流中的正常位置**进行定位：

```css
.box-relative {
  position: relative;
  left: 20px;   /* 向右偏移 20px */
  top: 40px;    /* 向下偏移 40px */
}
```

- **不脱离正常文档流**：元素虽然移动了位置，但它原来所占的位置仍然保留，下面的元素不会上浮
- 常用于**微调元素的位置**

### 3. 绝对定位 `absolute`
相对于**离它最近的、已经定位过的父元素**进行定位；如果祖先里没有已定位的父元素，就相对于 `html` 标签定位。

```css
.box-absolute {
  position: absolute;
  left: 120px;
}
```

- **脱离文档流**：不占据原来的位置，下面的元素会自动上浮补位
- 常用于配合父元素定位，创建更复杂的布局

### 4. 固定定位 `fixed`
相对于**浏览器窗口**进行定位：

```css
.box-fixed {
  position: fixed;
  right: 0;
  top: 300px;
}
```

- **脱离文档流**，不占据原位置
- 位置固定在窗口上，**页面滚动时也不会移动**
- 常见用途：顶部导航栏、侧边栏、悬浮的小图标 / 回到顶部按钮

### 5. 三种定位对照表
| 定位方式 | `position` 值 | 参照对象 | 是否脱离文档流 | 原位置是否保留 | 典型用途 |
|---|---|---|---|---|---|
| 相对定位 | `relative` | 自身在文档流中的正常位置 | 否 | ✅ 保留 | 微调元素位置 |
| 绝对定位 | `absolute` | 最近的已定位父元素（无则 `html`） | 是 | ❌ 不保留 | 复杂布局、父子定位 |
| 固定定位 | `fixed` | 浏览器窗口 | 是 | ❌ 不保留 | 导航栏、侧边栏、悬浮元素 |

> **理解思路**：相对定位是"站在原地挪一步"，位置还给你留着；绝对定位是"飘到最近的定位长辈身边"；固定定位是"钉在浏览器窗口上"，滚到哪都跟着。

### 6. 使用场景
- **相对定位**：微调元素位置
- **绝对定位 / 固定定位**：创建更复杂的布局
- 具体用哪种，取决于实际的设计需求

## 五、所有来一个举例，可运行的哦
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>CSS 布局练习</title>
  <style>
    /* 盒子模型：边框 + 内边距 + 外边距 */
    .box {
      width: 200px;
      background-color: lightblue;
      border: 3px solid yellowgreen;
      padding: 20px;
      margin: 10px;
    }

    /* 浮动：两个子盒子并排 */
    .father {
      border: 2px solid brown;
      overflow: hidden;   /* 清除浮动，撑开父元素 */
    }
    .left {
      float: left;
      width: 100px;
      height: 100px;
      background-color: yellowgreen;
    }
    .right {
      float: right;
      width: 100px;
      height: 100px;
      background-color: yellow;
    }

    /* 相对定位：微调位置，不脱标 */
    .relative-demo {
      position: relative;
      left: 20px;
      top: 10px;
      background-color: pink;
    }

    /* 绝对定位：参照最近已定位父元素 */
    .wrap {
      position: relative;
      height: 200px;
      background-color: #eee;
    }
    .absolute-demo {
      position: absolute;
      right: 20px;
      top: 20px;
      width: 100px;
      height: 100px;
      background-color: yellowgreen;
    }

    /* 固定定位：钉在窗口右侧，滚动不移动 */
    .fixed-demo {
      position: fixed;
      right: 0;
      top: 300px;
      width: 60px;
      height: 60px;
      background-color: brown;
    }
  </style>
</head>
<body>
  <div class="box">盒子模型：内容 + padding + border + margin</div>

  <div class="father">
    <div class="left">左浮动</div>
    <div class="right">右浮动</div>
  </div>

  <div class="relative-demo">相对定位：向右向下微调</div>

  <div class="wrap">
    <div class="absolute-demo">绝对定位</div>
  </div>

  <div class="fixed-demo">固定定位</div>
</body>
</html>
```
