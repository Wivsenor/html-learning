## 二、什么是 CSS
###  基本定义
- **全名**：Cascading Style Sheets，中文叫**层叠样式表**
- **作用**：一种用来定义网页样式和布局的样式表语言，一般和 HTML 一起配合构建网页
- **能控制什么**：元素的颜色、字体大小、间距、边框、背景等

---
## 三、CSS 基本语法
### 1. 组成结构
一条 CSS 规则由三部分组成：

```
选择器 {
  属性名: 属性值;
  属性名: 属性值;
}
```

- **选择器**：选择要应用样式的 HTML 元素（标签、类、id 等）
- **大括号 `{ }`**：里面的内容称为这条选择器的**声明**
- **声明**：可以写无数条属性，每条以**英文分号 `;`** 结尾

### 2. 键值对写法
属性和属性值以**键值对**形式出现：`属性名: 属性值;`，冒号分隔，分号收尾。

### 3. 示例
```css
p {
  color: blue;
  font-size: 16px;
}
```
意思：选中页面中**所有 `p` 标签**，把字体颜色改成蓝色，字体大小改成 16 像素。

> 💡 实操提示：VS Code 里输入 `fs` 可以补全 `font-size`；注释选中代码后按 `Ctrl + /`。

## 四、CSS 的三种导入方式
在 HTML 中应用样式有三种方式，目的都是把 CSS 接到网页上：

| 方式 | 写法位置 | 特点 | 优先级 |
|---|---|---|---|
| 内联样式（行内样式） | 直接写在元素的 `style` 属性里 | 只作用于当前这一个标签 | ⭐⭐⭐ 最高 |
| 内部样式表 | 写在 `head` 里的 `<style>` 标签中 | 作用于当前整个 HTML 文件 | ⭐⭐ 次之 |
| 外部样式表 | 单独一个 `.css` 文件，用 `<link>` 引入 | 可在多个页面重复复用同一套样式 | ⭐ 最低 |

### 1. 内联样式（行内样式）
把 CSS 直接嵌到元素标签内部，大部分标签都有 `style` 属性：

```html
<h1 style="color: red;">这是一个一级标题，使用内联样式</h1>
```

### 2. 内部样式表
把样式放在 HTML 文档的**头部 `head`** 标签中，用 `<style>` 标签包裹（通常放在 `<title>` 下面）：

```html
<head>
  <meta charset="UTF-8">
  <title>内部样式表练习</title>
  <style>
    p {
      color: blue;
      font-size: 26px;
    }
  </style>
</head>
```

> 注意：写了样式但页面里没有对应元素时，样式看不出来；把 HTML 元素注释掉，对应的样式效果也会消失。

### 3. 外部样式表
把 CSS 单独放到一个 `.css` 文件里，再在 `head` 中用 `<link>` 标签链接到 HTML 文档。

**目录结构：**
```
项目目录/
├─ index.html
└─ css/
   └─ style.css
```

**`style.css` 里写样式：**
```css
h3 {
  color: yellowgreen;
}
```

**`index.html` 的 `head` 中用 link 引入：**
```html
<head>
  <meta charset="UTF-8">
  <title>外部样式表练习</title>
  <link rel="stylesheet" href="css/style.css">
</head>
```

- `href` 填 css 文件的路径（这里用相对路径 `css/style.css`）
- **适用场景**：网站通常有多个网页，外部样式表正好可以跨页面复用同一套样式

### 4. 三种方式的优先级
不同导入方式优先级不同，**优先级高的样式会覆盖优先级低的样式**，从高到低：

```
内联样式  >  内部样式表  >  外部样式表
```

- 一个标签如果用了**内联样式**（等级最高），想改它的颜色，只能在内部样式表里再针对它写样式去覆盖
- 一个标签如果只用了**外部样式**，那么既可以用内联样式覆盖它，也可以用内部样式表覆盖它
- 反过来，给已经被内联样式定死的标签，再去写内部/外部样式，是**不起作用**的

> **理解思路**：谁离标签越近、写得越具体，谁的话语权就越大；内联样式直接挂在标签身上，所以优先级最高。

## 五、CSS 选择器
### 1. 什么是选择器
**选择器就是用于选择要应用样式的 HTML 元素**。可以选择所有元素、特定元素、特定的类、特定的 id，甚至是元素之间的层级 / 兄弟关系。CSS 语法以选择器开头，所以选择器非常重要。

### 2. 基础选择器（最常用）
#### （1）元素选择器（标签选择器）
直接写标签名，选中页面中所有该标签：
```css
hr {
  color: skyblue;
}
```

#### （2）类选择器
先给标签加 `class`，CSS 里在类名前加一个**点号 `.`**：
```html
<h3 class="highlight">这是一个类选择器示例</h3>
```
```css
.highlight {
  background-color: yellow;
}
```

- 同一个类名可以用在多个标签上；只想给带某个类的标签加样式时，类选择器比元素选择器更精准
- 类名可以随意起，见名知意即可

#### （3）id 选择器
先给标签加 `id`，CSS 里在 id 名前加一个**井号 `#`**：
```html
<h4 id="title">这是一个 id 选择器示例</h4>
```
```css
#title {
  font-size: 35px;
}
```

> ⚠️ `id` 在整个页面中必须**唯一**，一个 id 只能对应一个元素。

#### （4）通用选择器
用一个**星号 `*`**，选中页面中**所有元素**：
```css
* {
  font-family: 楷体;
  font-weight: bolder;
}
```

### 3. 关系选择器
#### （1）子元素选择器（子代选择器）
选择**直接位于父元素内部**的子元素（只选"儿子"，不选"孙子"）。语法：父元素后加**大于号 `>`**，再写子元素：
```css
.father > p {
  color: yellowgreen;
}
```

#### （2）后代选择器（包含选择器）
选择父元素内部的**所有后代元素**（儿子、孙子都算）。语法：父元素和后代之间用**空格**分隔：
```css
.father p {
  color: brown;
  font-size: larger;
}
```

**子代 vs 后代的区别：**
| | 范围 | 比喻 |
|---|---|---|
| 子元素 `>` | 只选直接下一层 | 只选儿子 |
| 后代（空格） | 选所有嵌套层级 | 儿子、孙子都选 |

> **理解思路**：子代属于后代。`div.father` 里直接包一个 `p` 是儿子；再嵌套一层 `div.grandson` 里的 `p` 是孙子，只能被后代选择器选中，不算子代。

#### （3）相邻兄弟选择器
选中同一层级下，**紧跟在某个元素之后的第一个**兄弟元素。语法：元素后加**加号 `+`**，再写后面的兄弟：
```css
h3 + p {
  background-color: red;
}
```

> 注意：它只选紧跟其后的**第一个**同级元素，上面的兄弟不会被选中。

### 4. 伪类选择器
- **作用**：选择 HTML 文档元素的**特定状态或位置**，而不只是元素本身的属性
- **写法**：以**单冒号 `:`** 开头，常用于用户交互、文档结构等条件下的元素

常用伪类：
| 伪类 | 含义 | 示例 |
|---|---|---|
| `:hover` | 鼠标悬停在元素上时 | `#element:hover { background-color: purple; }` |
| `:first-child` | 父元素中的第一个子元素 | `li:first-child { }` |
| `:nth-child(n)` | 父元素中的第 n 个子元素 | `li:nth-child(2) { }` |
| `:active` | 链接 / 元素被激活（按下）的状态 | `a:active { }` |

示例：鼠标放到标题上时出现紫色背景：
```css
#element:hover {
  background-color: purple;
}
```

### 5. 伪元素选择器
- **作用**：创建一个**虚拟元素**并给它加样式，而不是选择页面上实际存在的元素
- **写法**：以**双冒号 `::`** 开头，新手阶段用得不多

```css
::before   /* 在选中元素之前插入虚拟内容 */
::after    /* 在选中元素之后插入虚拟内容 */
```

### 6. 选择器的权重（优先级）
当多个选择器选中同一个元素时，权重高的生效，基本规律：

```
id 选择器  >  类选择器  >  标签（元素）选择器
```

> ⚠️ 注意和"导入方式优先级"区分：一个是**选择器本身的权重**，一个是**样式从哪里导入**，是两个不同维度。

## 六、CSS 常用属性
CSS 属性有上百个，但基础阶段只需要掌握一小部分，其他的要么重复、要么使用频率很低，用到时再查菜鸟教程 / W3School 即可。

### 1. 基础属性
| 属性 | 作用 |
|---|---|
| `color` | 字体颜色 |
| `background-color` | 背景颜色 |
| `font-size` | 字体大小 |
| `font-family` | 字体（如楷体） |
| `font-weight` | 字体粗细（如 `bolder`） |
| `font-style` | 字体样式（斜体等） |

### 2. 字体复合属性 `font`
`font` 是一个**复合属性**：可以通过**一个属性**同时设置多个字体样式（粗细、字号、字体系列等）。

```html
<h1 style="font: bolder 50px 楷体;">这是一个 font 复合属性示例</h1>
```

等价于拆开写：
```css
h1 {
  font-weight: bolder;
  font-size: 50px;
  font-family: 楷体;
}
```

### 3. 行高 `line-height`
设置行与行之间的距离。多行文本挤在一起、看着不舒服时，可以调大行高：
```css
p {
  line-height: 40px;
}
```

### 4. 宽高 `width` / `height`
- `width`：元素宽度
- `height`：元素高度

能不能设置宽高，取决于元素属于哪种类型。先回顾 HTML 里讲过的三种元素类型：

| 类型 | 代表标签 | 排列方式 | 默认宽度 | 能否设宽高 | 能否包含块级元素 |
|---|---|---|---|---|---|
| 块级元素 `block` | `div` | 另起一行，独占一行 | 占据整行宽度 | ✅ 可以 | 可包含块级 / 行内元素 |
| 行内元素 `inline` | `span` | 在同一行内排列 | 只占内容所需宽度 | ❌ 无效 | 不能包含块级元素，可包含行内元素 |
| 行内块元素 `inline-block` | `img` 图片 | 在同一行内排列 | 可自定义 | ✅ 可以 | 可包含行内 / 块级元素 |

**宽高设置规律：**
- **块级元素**：可以设宽高，例如 `width: 200px; height: 150px;`
- **行内块元素**：可以设宽高；只设宽度时图片按比例压缩，宽高同时设置可能被拉伸变形
- **行内元素**：宽高由里面的内容决定，设置 `width` / `height` 无效
- 一行里可以排多个行内块元素，但块级元素各自独占一行

### 5. `display` 属性：转换元素类型
块级、行内、行内块三种元素**可以互相转换**，靠的是 `display` 属性：

| `display` 值 | 转换成 | 说明 |
|---|---|---|
| `block` | 块级元素 | 独占一行，可设宽高 |
| `inline` | 行内元素 | 同一行排列，宽高由内容决定 |
| `inline-block` | 行内块元素 | 同一行排列，又能设宽高 |
| `none` | 不显示 | 元素在页面上隐藏，不占位置 |

示例：
```html
<div class="div-inline">转换成行内元素的 div</div>
<span class="span-inline-block">转换成行内块元素的 span</span>
```
```css
.div-inline {
  display: inline;
  background-color: blue;
}

.span-inline-block {
  display: inline-block;
  width: 300px;
  background-color: purple;
}
```

- 把 `div` 转成 `inline` 后，背景色不再独占一行
- 把 `span` 转成 `inline-block` 后，就可以给它设置宽度
- 把 `span` 转成 `block` 后，默认独占一行

> **理解思路**：商品列表里一排排的图片 + 文字，很多就是行内块元素；需要让普通标签获得它没有的排列 / 宽高特性时，就用 `display` 转换。

## 七、所有来一个举例，可运行的哦
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>CSS 基础练习</title>
  <style>
    /* 通用选择器：统一字体和加粗 */
    * {
      font-family: 楷体;
      font-weight: bolder;
    }

    /* 元素选择器：段落 */
    p {
      color: blue;
      line-height: 40px;
    }

    /* 类选择器 */
    .highlight {
      background-color: yellow;
    }

    /* id 选择器 */
    #title {
      font-size: 35px;
    }

    /* 子元素选择器 */
    .father > p {
      color: yellowgreen;
    }

    /* 后代选择器 */
    .father span {
      color: brown;
    }

    /* 伪类：悬停变色 */
    #title:hover {
      background-color: purple;
      color: white;
    }

    /* 行内块：图片可设宽高 */
    .pic {
      display: inline-block;
      width: 100px;
    }
  </style>
</head>
<body>
  <h1 id="title">CSS 基础入门练习</h1>

  <p class="highlight">这是一段应用了类选择器的段落，行高 40px。</p>

  <div class="father">
    <p>这是 father 的直接子元素（子元素选择器）。</p>
    <div>
      <span>这是 father 里的后代 span（后代选择器）。</span>
    </div>
  </div>

  <span>普通行内 span，不能设置宽高。</span>
  <img class="pic" src="logo.png" alt="logo">

  <!-- 内联样式：优先级最高 -->
  <h3 style="color: red;">这一行使用内联样式</h3>
</body>
</html>
```
