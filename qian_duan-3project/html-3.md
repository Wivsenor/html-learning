| 类别 | 标签 / 属性 | 作用 | 记忆点 |
|---|---|---|---|

## 二、属性基础
### 1. 什么是属性
每个 HTML 标签都可以带**一个或多个属性**，用来描述这个元素的**特征和行为**。

比如同一个段落，可以同时有 `id` 和 `class`：
```html
<p id="describe" class="section">这是一个段落</p>
```

### 2. 基本写法
- 属性写在**开始标签**的标签名**后面**
- 格式：`属性名="属性值"`
- 属性名与属性值之间用**等号** `=` 隔开
- 属性值一般用引号包起来，**单引号、双引号都可以**

### 3. 大小写规则（容易踩坑）
| 对象 | 是否区分大小写 | 例子 |
|---|---|---|
| 属性名 | ❌ 不区分 | `src` 和 `SRC` 效果完全一样 |
| 属性值 | ✅ 区分 | `example.jpg` 和 `EXAMPLE.jpg` 是两个不同文件 |



---
## 三、通用属性（大部分标签都能用）
| 属性 | 作用 | 说明 |
|---|---|---|
| `class` | 类属性 | 为标签定义一个或多个类名，后面写 CSS 时用 |
| `id` | 唯一标识 | 每个元素的 id 全页唯一，不能重复 |
| `style` | 行内样式 | 直接在标签上规定 CSS 样式 |

## 四、超链接标签 `a`
`a` 标签常用于创建指向其他网页或位置的链接。

### 1. `href` 属性
定义链接跳转的**目标地址**，可以是：其他网页 URL、文件路径、电子邮箱地址、手机号等。

```html
<a href="https://www.baidu.com">这是一个超链接</a>
```

> ⚠️ 注意：标签中间必须写文字内容，否则页面上什么都不显示。

### 2. `target` 属性
定义链接的**打开方式**：

| 属性值 | 含义 |
|---|---|
| `_self` | 默认值，在当前窗口 / 标签页打开 |
| `_blank` | 在新窗口 / 新标签页打开 |
| `_parent` | 在父窗口 / 父框架中打开 |
| `_top` | 在顶层窗口 / 顶层框架中打开 |

```html
<a href="https://www.baidu.com" target="_blank">在新标签页打开</a>
```

> **理解思路**：平时最常用的就是默认的 `_self`（当前页打开）和 `_blank`（新开一页），后两个 `_parent`、`_top` 是配合框架页面用的，先了解即可。

## 五、图片标签 `img`
`img` 用于在网页中嵌入图像，是**单标签**（没有结束标签）。

### 1. 核心属性
| 属性 | 作用 |
|---|---|
| `src` | 图片的路径或 URL（必需），可以是相对路径、绝对路径或网络地址 |
| `alt` | 图片加载不出来时，浏览器显示的替代文本 |
| `width` | 图片宽度 |
| `height` | 图片高度 |

```html
<!-- 本地图片 -->
<img src="logo.png" alt="该图片无法显示" width="200" height="100">

<!-- 网络图片 -->
<img src="https://example.com/image.jpg" alt="示例图片">
```

### 2. `alt` 的作用
- 当图片路径写错、加载失败时，页面就显示 `alt` 里写的文字
- `alt` 可以留空，但建议写上，方便后期维护

### 3. 宽高设置
图片默认会按原始尺寸显示，太大就用 `width`、`height` 限定大小，单位是像素。

## 六、其他实用标签
### 1. 换行标签 `br`
单标签，强制换行，相当于敲了一个回车：
```html
<p>第一行<br>第二行</p>
```

### 2. 水平线标签 `hr`
单标签，在页面上画一条水平分割线：
```html
<p>上面内容</p>
<hr>
<p>下面内容</p>
```

> 💡 伏笔：`a` 标签和 `img` 标签都属于**行内元素**，不会独占一行，多个可以排在同一行；想换行就靠 `br` 或 `hr`。块元素 / 行内元素下一节细讲。

## 七、所有来一个举例，可运行的哦
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>标签属性练习</title>
</head>
<body>
  <h1>我的前端学习笔记</h1>

  <!-- 超链接 -->
  <p>去 <a href="https://www.baidu.com">百度</a> 搜资料，
     <a href="https://www.bilibili.com" target="_blank">B站</a> 在新标签页打开。</p>

  <hr>

  <!-- 本地图片 + 网络图片 -->
  <img src="logo.png" alt="该图片无法显示" width="150" height="100">
  <br>
  <img src="https://example.com/image.jpg" alt="示例图片" width="200">

  <hr>

  <!-- 带通用属性的段落 -->
  <p id="intro" class="section" style="color: #333;">
    这段文字同时带了 id、class 和 style 三个通用属性。
  </p>
</body>
</html>
```
