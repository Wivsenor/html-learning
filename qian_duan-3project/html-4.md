# HTML 块元素与行内元素 · 学习笔记
> **主要内容**：《块元素与行内元素》
>
> **目的**：分清两类元素在浏览器里的排版表现，掌握 `div`、`span` 两个最常用的容器标签
---
## 一、分类总览
| 类别 | 标签 | 作用 | 记忆点 |
|---|---|---|---|
| 块元素 | `div` | 块级容器，搭页面大框架 | div = division 区块 |
| 块元素 | `p` | 段落 | 独占一行 |
| 块元素 | `h1` ~ `h6` | 标题 | 独占一行 |
| 块元素 | `ul` / `ol` | 无序 / 有序列表 | 独占一行 |
| 块元素 | `table` | 表格 | 独占一行 |
| 块元素 | `form` | 表单 | 独占一行 |
| 行内元素 | `span` | 行内容器，包一小段文字 | span = 跨度 |
| 行内元素 | `a` | 超链接 | 多个可挤在同一行 |
| 行内元素 | `strong` / `b` | 加粗 | 行内 |
| 行内元素 | `em` / `i` | 斜体 | 行内 |
| 行内元素 | `img` | 图片 | 行内 |
| 行内元素 | `br` | 换行 | 单标签 |
| 行内元素 | `input` | 输入框 | 表单里细讲 |
---------------------------------------------------------------------------
## 二、为什么要分这两类
因为有些标签在浏览器里**单独占一行**，别的元素不能跟它并排；有些标签则可以和别的元素**排在同一行**。

于是按元素在浏览器里的**实际表现形式**，把 HTML 元素分成两类：**块元素**和**行内元素**。

> ⚠️ 注意：说"独占一行"是指**浏览器显示出来的效果**，不是指 VS Code 代码文件里换没换行。代码里写在同一行，浏览器该换行照样换行。

> 💡 这是 HTML 里非常重要的概念，也是后面学 CSS 的前置内容。

---
## 三、块元素（Block）
### 1. 特点
- 从**新的一行**开始显示，占据**整行宽度**
- 在页面上呈现为一块独立的内容块
- 通常用来**组织和布局页面**（段落、标题、列表、表格等）
- 里面**可以再嵌套**其他块级元素和行内元素

### 2. 常见块元素
| 标签 | 说明 |
|---|---|
| `div` | 块级容器（最常用） |
| `p` | 段落 |
| `h1` ~ `h6` | 标题标签 |
| `ul` / `ol` | 无序列表 / 有序列表 |
| `table` | 表格标签 |
| `form` | 表单标签 |

---
## 四、行内元素（Inline）
### 1. 特点
- 在**同一行内**呈现，不独占一行
- 只占据**内容本身所需的宽度**，而不是整行
- 里面**不能再嵌套块级元素**，只能包含其他行内元素

### 2. 常见行内元素
| 标签 | 说明 |
|---|---|
| `span` | 行内容器 |
| `a` | 超链接 |
| `strong` / `b` | 加粗 |
| `em` / `i` | 斜体 |
| `img` | 图片标签 |
| `br` | 换行 |
| `input` | 输入标签（表单部分细讲） |

---
## 五、`div` 标签（块级容器）
### 1. 特点
- **块级标签**，独占一行
- **没有任何语义**，本身不代表段落、标题或列表，纯粹是个装内容的"盒子"
- 因为无语义、可嵌套，所以最常用来**划分页面布局结构**

### 2. 典型用途
把网页拆成不同区域：页眉、导航栏、侧边栏、中间内容区、页脚，每一块用一个 `div` 包起来。

```html
<!-- 导航栏 -->
<div class="navibar">
  <a href="#">链接一</a>
  <a href="#">链接二</a>
  <a href="#">链接三</a>
</div>

<!-- 主要内容区 -->
<div class="content">
  <h1>文章标题</h1>
  <p>文章内容段落一</p>
  <p>文章内容段落二</p>
</div>
```

### 3. VS Code 快捷写法
- 输入 `.类名` + `Tab` → 自动生成带 `class` 的 `div`
- 输入 `#id名` + `Tab` → 自动生成带 `id` 的 `div`
- 完整写法：`div.类名` 或 `div#id名`

---
## 六、`span` 标签（行内容器）
### 1. 特点
- **行内元素**，不独占一行，只占内容所需宽度
- 同样没有特殊语义，作用是把**一小部分文本**包装起来
- 方便后面用 CSS 改样式、或用 JS 加行为

```html
<p>这是一段文本，其中<span>这部分文字</span>需要单独处理。</p>
<p>更多信息请点击 <a href="#">这里</a> 查看。</p>
```

> **理解思路**：`span` 就相当于一个"没有特殊含义的 `a` / `img`"，只负责圈出行内的一小段内容。

---
## 七、`div` 与 `span` 对照表
| 对比项 | `div` | `span` |
|---|---|---|
| 类型 | 块级元素 | 行内元素 |
| 宽度 | 占满整行 | 只占内容宽度 |
| 用途 | 页面布局、大区域划分 | 局部文本样式标记 |
| 嵌套规则 | 可包含块级和行内元素 | 只能包含行内元素 |

> 💡 这两个标签本身不带样式意义，通常配合 CSS 和 JS 一起使用，才能做出复杂的页面布局和效果。

---
## 八、所有来一个举例，可运行的哦
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>块元素与行内元素练习</title>
</head>
<body>
  <!-- 块级：导航栏容器 -->
  <div class="navibar">
    <a href="#">首页</a>
    <a href="#">文章</a>
    <a href="#">关于</a>
  </div>

  <!-- 块级：内容区容器 -->
  <div class="content">
    <h1>我的学习页面</h1>
    <p>这段正文里，<span>标灰的一小段</span>用 span 包起来，
       后面可以单独改样式；<strong>加粗</strong>和<a href="#">链接</a>也都是行内元素。</p>
    <p>第二个段落又是一个独立的块，和上一段分开展示。</p>
  </div>
</body>
</html>
```
